## 1. 基本情報
| 項目 | 内容 |
| :--- | :--- |
| **レク名** | もしかめ（肩たたき） |
| **時間** | 5分くらい |
| **対象** | だれでも |
| **場所** | どこでも |
| **やるタイミング** | バスレク、ちょっとした時間、アイスブレイク |
| **隊形** | リーダーの前に子どもたちが散らばる形 |

---

## 2. やり方

"もしかめ"の曲に合わせて、左右交互に肩を叩く。

♪ もしもしかめよ かめさんよ（右8回）  
　世界の うちで お前ほど（左8回）  
　歩みの とろい（右4回）  
　者はない（左4回）  
　どうして（右2回）  
　そんなに（左2回）  
　とろい（右1回）  
　のか?（左1回）  
　手拍子（1回）

---

## 3. ポイント
- 数を伝えると、自分で考えて数えられる
- リーダーは子どもの鏡になって行う

---

## 4. アレンジ
- 1列（円になるも可）になって、前の人の肩を叩く
- スピードアップ
- 他のバージョンもやる（ワイパーバージョンとか）
- 歌なしで行う（8回目→8、4回目→8・4、1回目の時に手を叩く）

---

## 5. 終わらせ方
- 次の行動の指示
- 次のレク
