## 1. 基本情報
| 項目 | 内容 |

| **ゲーム名** | はだしのリス |
| **時間** | 3〜5分（ちょっとしたスキマ時間にオススメ） |
| **人数** | 何人でも |
| **場所** | どこでも |
| **対象** | だれでも |
| **分類** | リーダー対みんな / バスレク |
| **隊形** | リーダーが見えるところになる |

---

## 2. 進め方
1. **導入**
   - リーダーの見えるところに集まって座る。
2. **レクスタート**
   - 左手を土台にして、その上を右手の人差し指と中指で「トコトコ」あるいていくイメージで手を見せる。
   - 「トコトコトコ…これは『はだしのリス』」
   - 「トコトコトコ…これは『普通のリス』」
   - 「トコトコトコ…じゃあこれは？」
3. **クイズ（本番）**
   - （はだしのリスか、普通のリスか）どちらか当ててもらう。
   - ※「普通のリスも裸足じゃん！」というツッコミは華麗にスルーする。
4. **繰り返し**
   - 何度もする。

---

## 3. ポイント
- **＜たねあかし＞**
  - 「じゃあこれは？」の時に、リーダーの歯が出ていたら「はだしのリス」。
- わかった子、わかった気でいる子には、当ててみよう。
- やりすぎるとあきるので注意。

---

## 4. アレンジ（飽きさせない工夫）
- **他のレクとあわせて**
  - この「はだしのリス」の次に、内緒話で「セブンイレブン」や「チョコレート」といったレクに展開する。

---

## 5. 終わらせ方
「さいごにするよー」

---

## 6. このレクの次にできること
