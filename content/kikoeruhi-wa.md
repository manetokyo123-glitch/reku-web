## 1. 基本情報
| 項目 | 内容 |
| :--- | :--- |
| **ゲーム名** | 〇〇の声が聞こえる人は |
| **時間** | 3〜5分くらい |
| **人数** | 何人でも |
| **場所** | どこでもOK |
| **対象** | だれでも |
| **分類** | リーダー対みんな / バスレク / その他（注目あつめ） |
| **隊形** | 自由 |

---

## 2. 進め方
1. **導入**
   - 急にはじめて大丈夫。少しずつ全体に「聞く姿勢」がひろがります。
2. **レクスタート**
   - 「〇〇（自分のキャンプネーム）の声が聞こえる人は、×××して〜。」と呼びかける。
3. **繰り返し**
   - ひたすらくりかえし。

---

## 3. ポイント
- 声は大きく、はっきりと。
- 「×××して」のレパートリーを考えておく。

---

## 4. アレンジ（飽きさせない工夫）
- あそびの中で指示を出す。
- 次のレクがやりやすいようにグループわけなどをする。

---

## 5. 終わらせ方
全員が注目できて、楽しめたらおわる。

---
