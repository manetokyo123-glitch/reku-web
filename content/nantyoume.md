| **ゲーム名** | 何丁目？ |
| **時間** | 3〜5分くらい（ちょっとした時間にできます） |

| **対象** | だれでも |
| **分類** | リーダー対みんな/バスレク |
| **隊形** | リーダーが見えるところにいればどんな隊形でもOK |

---

## 2. 進め方
1. **導入**
   - 「クイズです」と呼びかけて注目させる。
2. **場所を教える**
   - 自分の腕などの場所を順番に触りながら、「1丁目、2丁目、3丁目、4丁目、5丁目、6丁目」と教える。
   - （図：①左手 ②左ひじ ③左肩 ④右肩 ⑤右ひじ ⑥右肩）
3. **クイズを出す（本番）**
   - 「じゃあ①、ここは②、何丁③、目④？」と声をかけながら、好きなところを4回触る。
   - **【正解のルール】** 「ここは」と言った時に触っていた場所が正解になる。
4. **回答**
   - 子どもたちに何丁目か当ててもらう。

---

## 3. ポイント
- 動きはみんなに見えるようにわかりやすくする。
- ある程度わかった子が増えてきたら、前に来て耳打ちで答えてもらう。
  - 正解の場合：「ピンポーン、まだみんなにはナイショね」
  - 不正解の場合：「ブブー。ちがうよん」
- しつこくやりすぎるとあきる。

---

## 4. アレンジ（飽きさせない工夫）
- 答えがわかった子に出てもらう（リーダーの代わりに問題を出してもらう）。
- 丁目の場所をかえる。

自由。
